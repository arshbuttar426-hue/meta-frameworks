### Resonance Routing

When a problem enters Orion, each node computes `sense(problem)`. Nodes with resonance ≥ 0.6 activate and respond. The MycelialNetwork routes the problem to activated nodes in parallel. Silent nodes (resonance < 0.6) do not block — they simply don't speak.

```python
class OrionMycelium:
    def __init__(self):
        self.nodes = {f"N{i}": CreativeNode(f"N{i}", DOMAIN[i]) for i in range(12)}
        self._seed_bonds()

    def route(self, problem: str) -> list[CreativeNode]:
        return [n for n in self.nodes.values() if n.sense(problem) >= 0.6]

    def reinforce(self, from_id: str, to_id: str, weight: float) -> None:
        self.nodes[from_id].connection_strengths[to_id] = (
            self.nodes[from_id].connection_strengths.get(to_id, 0.0) + weight
        )
```

The mycelium is alive: it grows new bonds when domains co-activate on successful merges. Bonds that don't work are NOT pruned automatically — they persist until explicitly commanded to remove. Contradiction is data, not deletion.
